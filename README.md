# Ethiopian Emergency Hub

A mobile application designed to assist users during emergencies by providing location tracking, direct SMS alerts, and quick access to emergency service centers.

## 📱 Features
* **Emergency Alerts:** Send immediate SMS notifications with real-time location.
* **Location Tracking:** Find nearby emergency service centers and medical hubs.
* **Database Integration:** Local and remote data management for reliable usage.

## 🛠 Tech Stack
* **Language:** Java
* **Platform:** Android Studio
* **Database:** SQLite & MySQL
